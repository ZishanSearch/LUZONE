# LUZONE

LUZONE is a simple image generation UI that lets you upload a target style image and your face image to preview a combined output, along with a persistent history.

## Usage

1. Open `index.html` in a browser.
2. Upload a target image and a face image.
3. Adjust the **Style Blend** slider if you want more or less of the target look.
4. Click **Generate Image** to preview the output and save it to history.

## Notes

This is a front-end demo experience meant to show the workflow and UI. The blend control and canvas compositing simulate style transfer locally in the browser.
